# 차형 캐릭터 설정서 v3 (상품화 고려)

**확정 기준 그림:** `assets/character/chahyung_v3_base.png` (배경 제거본) · 원본 `assets/character/chahyung_v3_base_raw.png`
(v2.1 기준 그림 `assets/character/chahyung_base.png`는 기록으로 보관)

채널: **차를 읽는 시간** · 캐릭터: **차형**

## 1. 설계 원칙
상품, 이모티콘, 굿즈로 넓힐 것을 처음부터 고려한다.
1. **실루엣:** 그림자만 봐도 차형인 줄 알 수 있어야 한다. 둥근 큰 머리(짧은 검은 머리)와 통통한 레이싱 슈트 몸이 핵심이다.
2. **작게 줄여도 성립:** 64px 아이콘, 2cm 스티커, 키링에서도 표정이 보여야 한다.
3. **적은 색:** 기본 6색 안에서 인쇄, 자수, 굿즈 제작이 쉬워야 한다.
4. **단순한 선:** 굵고 일정한 외곽선, 그라데이션·주름·광택 없는 단색 채색을 쓴다. 벡터로 옮기기 쉬워야 한다.
5. **얼굴이 정체성:** 마시멜로 얼굴, 웃는 실눈, 발그레한 볼은 어떤 버전에서도 바꾸지 않는다.
6. **자동차 채널임이 한눈에:** 레이싱 슈트로 자동차 이야기꾼임을 보여 주되, 실제 레이싱팀·회사처럼 보이지 않게 로고·패치는 쓰지 않는다.

## 2. 외형 고정값
| 항목 | 설정 |
|---|---|
| 비율 | **2등신** (머리 : 몸 = 1 : 1), 몸은 둥근 떡 모양 |
| 얼굴 | 마시멜로처럼 하얗고 동그란 얼굴, 발그레한 볼 2개 |
| 눈 | 평소에는 웃는 실눈(^ ^). 놀랄 때만 작은 점 눈 |
| 입 | 작고 단순한 미소 |
| 머리 | **모자 없음.** 짧고 단정한 검은 머리, 옆머리만 살짝 희끗 |
| 상징물 1 | **빨간 레이싱 슈트** (위아래 한 벌). 검은 스탠드 깃, 가운데 지퍼(앰버 손잡이), 양 옆구리 검은 곡선 패널, 검은 벨트, 소매 끝·발목 검은 밴드, 한쪽 어깨에서 소매 끝까지 흰 줄 1줄 |
| 가슴 글자 | 왼쪽 가슴에 흰 굵은 영문 **CHAHYUNG** 한 줄. 이 밖의 글자·로고·숫자·패치는 넣지 않음 |
| 상징물 2 | **앰버색 자동차 모양 열쇠고리** (정지 그림: 주먹에서 짧은 끈으로 늘어뜨림 / 동작 그림: 검지에 걸고 돌림) |
| 신발 | 앰버색 단순한 둥근 신발 (끈 없음) |
| 손 | 하얀 둥근 장갑 모양, 손가락은 표현이 필요할 때만 |
| 소품(선택) | 둘둘 만 잡지. 표지 그림 없이 검정 한 색 |

- 빨간 배경 위에서는 슈트가 묻히므로 흰 테두리나 앰버 원 배경을 깐다.

## 4. 시그니처
- **열쇠 돌리기:** 검지에 건 앰버색 자동차 열쇠고리를 빙글 돌린다. 등장과 자신감을 표현한다.
- **잡지 펼치기:** 잡지를 펼치면 그날의 차가 튀어나온다. 장면 전환에 쓴다.

## 5. 말투
- 존댓말 + 편한 수다체
- 예: "이거 아세요?", "그 시절엔 말이죠…", "짜장면도 못 먹고요."

## 6. 필요한 그림 목록 (제작 순서)
1. 기본 정면 전신 (기준) — v3 완료
2. 턴어라운드: 정면 / 옆면 / 뒷면
3. 표정 시트: 기본 웃음, 깜짝 놀람, 신남, 곰곰이, 머쓱, 엄지척 윙크
4. 동작: 설명, 가리키기, 열쇠 돌리기, 잡지 펼치기, 엄지척
5. 프로필 (원형 얼굴 클로즈업) — v3 완료 (`assets/character/ip/`)
6. 실루엣 테스트 (검은 단색) — v3 완료

제미나이로 만들 때는 v3 기준 그림을 첨부하고, 배경은 평평한 초록(#00FF00)으로 요청한다. 배경 제거: `python3 tools/green_key.py 입력.png 출력.png`

## 7. 권리 메모
- AI로만 만든 그림은 저작권 보호가 약하거나 인정되지 않을 수 있다.
- 상품화 전에 이렇게 한다.
  - AI 그림을 시안으로 삼아 디자이너가 직접 벡터로 다듬는다.
  - 캐릭터 이름과 모습을 상표로 등록한다. 가슴의 영문 CHAHYUNG도 그림 상표에 함께 들어간다.
- 정확한 범위는 변리사 등 전문가에게 확인한다.
