# 차형 캐릭터 설정서 v2 (상품화 고려)

**확정 기준 그림:** `assets/character/chahyung_base.png` (배경 제거본) · 원본 `assets/character/chahyung_base_raw.png`

채널: **차를 읽는 시간** · 캐릭터: **차형**

## 1. 설계 원칙
상품, 이모티콘, 굿즈로 넓힐 것을 처음부터 고려한다.
1. **실루엣:** 그림자만 봐도 차형인 줄 알 수 있어야 한다. 드라이빙 캡과 둥근 큰 머리가 핵심이다.
2. **작게 줄여도 성립:** 64px 아이콘, 2cm 스티커, 키링에서도 표정이 보여야 한다.
3. **적은 색:** 기본 5색 안에서 인쇄, 자수, 굿즈 제작이 쉬워야 한다.
4. **단순한 선:** 굵고 일정한 외곽선, 그라데이션 없는 단색 채색을 쓴다. 벡터로 옮기기 쉬워야 한다.
5. **얼굴이 정체성:** 마시멜로 얼굴, 웃는 실눈, 발그레한 볼은 어떤 버전에서도 바꾸지 않는다.

## 2. 외형 고정값
| 항목 | 설정 |
|---|---|
| 비율 | **2등신** (머리 : 몸 = 1 : 1), 몸은 둥근 떡 모양 |
| 얼굴 | 마시멜로처럼 하얗고 동그란 얼굴, 발그레한 볼 2개 |
| 눈 | 평소에는 웃는 실눈(^ ^). 놀랄 때만 작은 점 눈 |
| 입 | 작고 단순한 미소 |
| 머리 | 짧은 검은 머리, 옆머리만 살짝 희끗. 모자 아래로 조금만 보임 |
| 상징물 1 | **남색 드라이빙 캡(헌팅캡)**, 앞챙에 앰버색 작은 단추 하나 |
| 상징물 2 | **앰버색 자동차 모양 열쇠고리** (늘 손가락에 걸고 있음) |
| 옷 | 남색 셔츠 한 벌 (단추, 주머니 없음), 깃만 앰버색 테두리 |
| 하의 | 베이지 바지, 짧고 단순하게 |
| 신발 | 앰버색 단순한 둥근 신발 (끈 없음) |
| 손 | 둥근 장갑 모양, 손가락은 표현이 필요할 때만 |
| 소품(선택) | 둘둘 만 잡지. 표지 그림 없이 남색 한 색 |

## 4. 시그니처
- **열쇠 돌리기:** 검지에 건 앰버색 자동차 열쇠고리를 빙글 돌린다. 등장과 자신감을 표현한다.
- **잡지 펼치기:** 잡지를 펼치면 그날의 차가 튀어나온다. 장면 전환에 쓴다.

## 5. 말투
- 존댓말 + 편한 수다체
- 예: "이거 아세요?", "그 시절엔 말이죠…", "짜장면도 못 먹고요."

## 6. 필요한 그림 목록 (제작 순서)
1. 기본 정면 전신 (기준)
2. 턴어라운드: 정면 / 옆면 / 뒷면
3. 표정 시트: 기본 웃음, 깜짝 놀람, 신남, 곰곰이, 머쓱, 엄지척 윙크
4. 동작: 설명, 가리키기, 열쇠 돌리기, 잡지 펼치기, 엄지척
5. 프로필 (원형 얼굴 클로즈업)
6. 실루엣 테스트 (검은 단색)

## 7. 권리 메모
- AI로만 만든 그림은 저작권 보호가 약하거나 인정되지 않을 수 있다.
- 상품화 전에 이렇게 한다.
  - AI 그림을 시안으로 삼아 디자이너가 직접 벡터로 다듬는다.
  - 캐릭터 이름과 모습을 상표로 등록한다.
- 정확한 범위는 변리사 등 전문가에게 확인한다.
