### 7-3. CC BY-SA 사진을 쓸 때 지킬 조건 (채택 기준)

1. **표기:** 영상 설명란·캡션에 위 ‘게시용 크레딧’ 전체를 넣고, 영상 0~25초 화면 왼쪽 위에 `사진 출처: 설명란 참고`를 작게(24px) 표시.

3. **동일조건:** 편집한 사진 자체(번호판을 흐린 A 등)는 같은 CC BY-SA로 공유한다고 설명란에 명시(“편집한 사진은 원본과 같은 CC BY-SA 라이선스를 따릅니다”). 원하면 편집한 정지 이미지 파일을 Commons에 올려 링크.
4. **추가 제한 금지:** 이 사진들에 대해 “무단 사용 금지” 같은 문구를 붙이지 않음. 영상 전체에 워터마크 저작권 문구를 넣을 경우 “사진 제외”를 명시.
5. 이 조건을 지키기 어렵다면(예: 영상을 광고로 집행하며 설명란을 쓸 수 없음) 사진 대신 **매장 근처 실제 각그랜저 소유주에게 촬영 허락을 받아 직접 찍는 것**이 가장 안전합니다.

### 링크 동선 확인 결과
- **유튜브 쇼츠:** 2023년 8월 31일부터 쇼츠 설명란·댓글의 URL은 클릭되지 않습니다([YouTube 고객센터 안내](https://support.google.com/youtube/answer/13748639), [TechCrunch](https://techcrunch.com/2023/08/10/youtube-is-disabling-links-on-shorts-to-cut-down-on-spam)). 클릭 가능한 링크는 **채널 프로필(채널 홈 링크)**입니다. → 영상의 “프로필 상담 링크”와 맞습니다. 채널 정보 > 링크에 상담 URL을 먼저 등록하세요.
