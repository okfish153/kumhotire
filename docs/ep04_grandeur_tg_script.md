# EP04 그랜저 TG · 1분 쇼츠 대본 (초안 1)

- 고정 제목: **전성기의 문을 열다** / **출시 첫날 1만 1,362대 계약** (사용자 지정 제목: 전성기의 문을 열다)
- 훅: 출시 첫날 계약 1만 1,362대 (승용차 사상 최고)
- 미끼: "진짜 기록은 그해 겨울" → 8번 월 1만 대로 회수
- 끝: 구독·댓글 요청 없이, 흥미로운 사실(2009년에도 월 1만 대)과 첫 문장으로 이어지는 말로 마무리 (2026-11-25 사용자 요청)
- 음성: 구글 클라우드 TTS `ko-KR-Chirp3-HD-Algenib` (`tools/tts_lines.py`)
