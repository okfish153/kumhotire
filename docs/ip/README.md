# 차형 IP 자료

| 파일 | 내용 |
|---|---|
| `01_character_bible.md` | 성격, 말투, 세계관, 쓰임 규칙. 설정서와 기준 그림이 다른 부분 정리 |
| `02_trademark_prep.md` | 상표 출원 준비: 상표 3건, 분류 추천, 비용, KIPRIS 검색 방법 |
| `03_creation_record.md` | 창작 과정 기록 (권리 증거용) |
| `../../assets/character/ip/` | 채널 아이콘, 실루엣, 크기 확인, 사용 가이드(PNG/PDF), 벡터 초안(SVG) |

다시 만들기:
- `python3 tools/make_ip_assets.py`: 프로필, 실루엣, 크기 확인 이미지
- `python3 tools/make_style_guide.py`: 사용 가이드 한 장
- `python3 tools/vectorize_draft.py`: SVG 벡터 초안
