# 차형 캐릭터 바이블 v1.1

> 외형과 색상의 고정값은 `docs/character_chahyung.md`(설정서 v2.1)를 따른다. 이 문서는 **성격, 말, 세계관, 쓰임 규칙**을 정한다.

## 1. 한 줄 소개
**"옛날 차 이야기를 들려주는 동네 형, 차형."**
오래된 자동차 잡지를 펼치면 그 시절 차가 튀어나온다. 숫자는 정확하게, 이야기는 재미있게 들려준다.

## 2. 기본 정보
| 항목 | 내용 |
|---|---|
| 이름 | 차형 (車 + 형) |
| 이름 뜻 | 차 이야기라면 언제든 들려주는 편한 형님 |
| 채널 | 차를 읽는 시간 |
| 나이 | 비밀. 다만 각그랜저가 처음 나오던 날을 기억한다 |
| 직업 | 옛날 자동차 잡지 수집가 겸 이야기꾼 |
| 늘 가진 것 | 남색 헌팅캡, 앰버색 자동차 열쇠고리, 둘둘 만 잡지 |
| 시청자와의 관계 | 단골 손님. 존댓말을 쓰지만 거리감은 없다 |

## 3. 성격 (3가지 핵심)
1. **꼼꼼한 이야기꾼:** 숫자와 연도는 반드시 확인한 것만 말한다. 모르면 모른다고 한다.
2. **넉살 좋은 수다쟁이:** 딱딱한 정보도 "짜장면 몇 그릇"처럼 생활 감각으로 바꿔 말한다.
3. **추억에 약한 사람:** 옛날 차 이야기를 하다 보면 눈이 더 가늘어진다(더 웃는다).

## 4. 말투
- **기본:** 존댓말 + 편한 수다체. 반말은 쓰지 않는다.
- **말버릇:**
  - "이거 아세요?" (이야기 시작)
  - "그 시절엔 말이죠…" (회상)
  - "…짜장면도 못 먹고요." (생활 감각 농담)
  - "근데 여기서 재밌는 게," (전환)
- **피하는 말:** 비속어, 다른 브랜드·차를 깎아내리는 말, 확인 안 된 "최초·최고·유일", 시청자를 가르치려 드는 말.

## 5. 세계관
- **잡지:** 차형의 잡지는 표지에 그림이 없는 남색 잡지다. 펼치면 그날 이야기할 차가 튀어나온다. 이것이 장면 전환의 기본 장치다.
- **열쇠고리:** 앰버색 자동차 모양 열쇠고리를 검지에 걸고 돌린다. 등장, 자신감, "출발합시다"의 신호다.
- **시대 여행:** 열쇠를 돌리면 그 차가 나온 해의 거리 풍경으로 바뀐다. 시대 풍경은 일러스트로만 그린다.

## 6. 쓰임 규칙
### 해도 되는 것
- 영상 아래 구석에서 반응하기(놀람, 엄지척, 가리키기)
- 채널 아이콘, 썸네일 한쪽, 댓글 고정용 이미지
- 굿즈 시안(스티커, 키링, 열쇠고리 모양 그대로)

### 하지 않는 것
| 금지 | 이유 |
|---|---|
| 운전 중 위험한 행동, 안전벨트 안 맨 운전 장면 | 안전 |
| 술, 담배와 함께 등장 | 주 시청자층이 넓고 굿즈 확장에 불리 |
| 정치, 종교 의견 | 채널 성격과 맞지 않음 |
| 특정 자동차 회사의 공식 캐릭터처럼 보이는 연출 (로고를 몸에 붙이기 등) | 상표 문제, 오해 |
| 얼굴 고정값 바꾸기 (실눈, 볼, 마시멜로 얼굴) | 정체성 |
| 색 바꾸기 (모자·셔츠 남색, 포인트 앰버) | 알아보기 쉬움 |
| 비율 바꾸기 (2등신이 아닌 늘씬한 버전) | 실루엣 정체성 |
