# 차형 창작 과정 기록

> 목적: 나중에 권리(저작권 등록, 분쟁 대응)를 주장할 때 **누가, 언제, 어떻게** 만들었는지 보여 주는 증거를 모은다. AI로 만든 부분과 사람이 결정·수정한 부분을 나눠 적는 것이 핵심이다.

## 1. 기록 원칙
- 원본 파일은 지우지 않는다. 고친 파일은 새 이름으로 저장한다.
- 파일마다 날짜와 지문값(SHA-256)을 남긴다. 파일이 나중에 바뀌지 않았음을 보여 준다.
- GitHub 저장소의 커밋 기록이 날짜 증거가 된다. 드라이브 `01_캐릭터_차형/`에도 같은 파일을 보관한다.
- 제미나이 앱에서 쓴 **프롬프트와 생성 화면 캡처**를 날짜별로 모은다. (사용자 보관 필요)

## 5. 저작권 메모
- 국내 정부 안내에 따르면 AI가 만든 결과물 자체는 저작권 등록 대상이 아니다. 사람이 선택·배열·수정한 창작 부분만 보호될 수 있다.
- 그래서 **디자이너가 직접 다시 그린 벡터 최종본**을 저작권 등록 대상으로 삼는 것을 추천한다. 이 기록 문서가 그 과정을 보여 주는 자료가 된다.
- 정확한 범위는 변리사·저작권 전문가에게 확인한다.

## 6. 생성 프롬프트 기록
### v3 기준 그림 (2026-11-22, 제미나이 앱, 사용자 입력)
첨부: ① v2.1 기준 그림 `chahyung_base.png` ② 사용자가 고른 레이싱 슈트 사진(브랜드 로고 있음, 참고용)

```
첫 번째 첨부 그림의 캐릭터를 얼굴·비율·그림체는 그대로 두고, 옷을 두 번째 사진 같은 레이싱 슈트를 아주 단순하게 바꿔 입혀 주세요. 모자는 쓰지 않습니다.
그대로 둘 것: 2등신(머리:몸 = 1:1), 마시멜로처럼 하얗고 둥근 큰 얼굴, 웃는 실눈, 발그레한 볼 2개, 하얀 둥근 장갑 손, 굵고 일정한 검은 외곽선, 그라데이션·주름·광택 없는 단색 채색.
머리: 모자가 없으니 짧고 단정한 검은 머리가 보이게, 옆머리만 살짝 희끗.
레이싱 슈트: 위아래가 한 벌로 이어진 빨간색 슈트, 짧은 스탠드 깃(검은색), 가운데 지퍼, 양쪽 옆구리에 검은색 곡선 패널, 어깨에서 소매 끝까지 하얀 줄무늬 2줄, 허리에 검은 벨트. 다리 부분도 같은 빨간 슈트로 짧고 단순하게.
신발: 앰버색 둥근 신발.
글자: 왼쪽 가슴에만 하얀색 굵은 영문 "CHAHYUNG" 한 줄. 다른 글자·로고·숫자·패치·엠블럼은 절대 넣지 마세요.
자세: 정면으로 서서, 한 손 주먹에서 짧은 끈으로 앰버색 자동차 모양 열쇠고리를 늘어뜨림.
배경: 완전히 평평한 초록색(#00FF00) 한 가지 색, 그림자·바닥 없음, 전신이 잘리지 않게, 세로 그림.
```
- 결과 그림은 줄무늬를 한쪽 팔에 1줄로 그렸고, 사용자가 이 그림을 그대로 확정했다(설정서 v3은 그림 기준).
