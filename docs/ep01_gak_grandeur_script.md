# EP01 각그랜저 · 1분 쇼츠 대본 (초안 2, 채택)

- 형식: 1분 이내 · 위 고정 2줄 제목 / 가운데 영상 / 아래 큰 자막 · 차형 말투(존댓말 + 편한 수다체)
- 고정 제목: **짜장면 28,000그릇 값?** / **지금 짜장면 값으론 2억!**
- 구성: 훅 → 2억 → 미끼(숨은 창) → 퀴즈 → 월급 → 각그랜저 → 회장님 차 → 미끼 회수(오페라 글라스) → 댓글 → 구독 → 첫 문장으로 이어지는 끝 문장
- 초안 1(238자, 12문장)은 이전 대화에만 있고 저장되지 않아, 같은 구성으로 다시 썼다.
