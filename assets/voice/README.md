# 나레이션 음성 파일 넣는 곳 (Typecast 등)

`make_video.py`는 이 폴더에 음성 파일이 있으면 그 음성을 먼저 사용합니다.

**방법 A: 단락별 6개 파일 (가장 정확함)**
`01.mp3` ~ `06.mp3`처럼 이름순으로 정렬되게 넣으세요. wav/mp3/m4a 모두 가능합니다.

**방법 B: 전체 1개 파일**
파일 하나만 넣으면 단락 사이 무음을 찾아 6조각으로 자동으로 자릅니다.
단락 사이 쉼은 1초 정도로 주세요.

대본 6단락:
1. 타이어 바꾸실 때, 가격만 보세요?
2. 잠깐! 타이어는 가격도 중요하지만, 내 차에 맞는 선택이 더 중요합니다!
3. 타이어 상태부터 마모, 휠얼라인먼트까지 꼼꼼하게!
4. 금호타이어 전문점! 내 차에 맞는 타이어를 합리적으로!
5. 교환부터 휠얼라인먼트까지 한곳에서!
6. 타이어 교환 고민 중이세요? 나주 금호타이어 송월점! 지금 상담해 보세요!
