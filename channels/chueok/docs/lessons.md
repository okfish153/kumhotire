# 교훈과 체크리스트 (「차를 읽는 시간」에서 배운 것)

## 교훈
1. **숫자는 1차 자료로.** 그 시절 신문 기사(예: 1992-09-17 한국일보 신차 가격)가 블로그·위키보다 우선. 자료가 엇갈리면 쓰지 않는다(예: 출시가 2,527만 vs 2,587만 → 생략).
2. **환산은 방법을 밝힌다.** "짜장면 2만 8천 그릇 = 지금 짜장면 값으로 2억"처럼, 물가 환산이 아님을 자막·설명란에 적는다. 월급 환산은 "한 푼도 안 쓰고 모은다고 가정".
3. **사건·사고는 공식 발표만.** 원인(예: 과속)을 분명히 말하고, "이것 덕분에 살았다" 같은 단정 금지. 횟수를 모르면 "여러 번". 비슷한 다른 사건과 헷갈리지 않게 연도를 늘 함께 쓴다.
4. **기업 뉴스룸 사진은 함부로 쓰지 않는다.** 약관에 서면 허락 없는 게시·상업 이용 금지가 있었다. 사실 확인용 글만 읽고, 사진은 Commons에서.
5. **Commons 사진:** 저작자·라이선스를 파일 페이지(또는 API)로 확인하고, 크레딧에 파일 이름·저작자·라이선스·편집 내용(크롭·번호판 흐림)을 적는다. CC BY-SA 편집본은 같은 라이선스.
6. **첫 화면이 썸네일.** 첫 프레임에 제목·핵심 숫자·사진이 다 보여야 한다. 처음 0.5초에 글자가 날아 들어오면 썸네일이 비어 보인다.
7. **끝 문장 → 첫 문장.** 쉼표로 끝내 한 문장처럼 이어지게(예: "근데 이 모든 기록의 시작이 바로," → "출시 첫날, …"). 끝 화면을 첫 화면과 같게.
8. **영상 안 구독·댓글 요청은 뺀다.** 그 자리에 흥미로운 사실을 넣으니 끝까지 보는 맛이 생겼다. 참여 요청은 설명란·고정 댓글로.
9. **퀴즈 + 하나·둘·셋**이 집중도를 올린다. 짧은 소리("셋!")는 따로 만들면 잘리니 "하나... 둘... 셋!"을 한 번에 만든다.
10. **홍보 쇼츠는 더 빠르게.** 문장마다 컷, 펀치 줌, 번쩍임, 충격 대목 흔들림, 효과음.
11. **플랫폼 한도:** 인스타 해시태그 최대 5개, 유튜브 쇼츠 최대 3분(4분은 일반 영상), 인스타 릴스 최대 3분.
12. **문서 저장:** 구글 문서로 바꿀 때 이모지가 깨진다 → 이모지 없이. 특수 기호(✔ ✕ ○)는 글꼴에 없을 수 있어 글자로.
13. **AI 음성:** 구글 클라우드 TTS를 쓴다(키는 클라우드 환경에 저장됨). 타입캐스트 무료 계정은 클라우드에서 막힘.

## 게시 전 체크리스트
- [ ] 콘텐츠 목록 중복 확인
- [ ] 근거 표의 기사 원문을 한 번씩 열어 숫자 확인
- [ ] 사진 저작자·라이선스 확인, 번호판·얼굴 흐림
- [ ] 첫 프레임 = 썸네일로 쓸 만한지
- [ ] 끝 문장이 첫 문장으로 이어지는지
- [ ] 영상 안 구독·댓글 요청·시리즈 번호·다음 편 예고 없음
- [ ] 업로드 글 5종에 크레딧이 빠짐없이 있는지, 해시태그 개수
- [ ] 자막 파일(.srt) 업로드, AI 표시(틱톡)
- [ ] 콘텐츠 목록에 한 줄 추가, 드라이브 저장
